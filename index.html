UniZodiac Backup

UniZodiac Backup is a private utility operated by nexplory to back up its own development website data to an owner-authorized Google Drive account. It is used by the owner and authorized administrators, and is not a public backup service.

Purpose and access

The utility uploads encrypted recovery copies and checks that the stored files match the uploaded copies. It requests the drive.file permission, which allows it to create, read, edit and delete files created by, or explicitly made available to, this app. The backup workflow does not access unrelated Drive documents or automatically delete cloud backups.

Your control

The account owner controls authorization and stored backup files. Access can be revoked through Google Account connections.

See the privacy notice for how data is accessed, used, stored and shared, and the use information for the intended audience and limitations.
